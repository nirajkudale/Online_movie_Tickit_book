# 🎬 Online Movie Ticket Booking System

A web-based application developed using ASP.NET MVC and Microsoft SQL Server to facilitate movie ticket bookings online. The system allows users to view movies, check showtimes, select seats, and securely complete their bookings.

---

## 📌 Project Features
### 👤 User Module
- Register/Login (with session-based authentication)
- Browse Movies and Theaters
- View Showtimes by Movie or Theater
- Select Seats (Standard / VIP)
- Booking Summary with Pricing Breakdown
- Multiple Payment Options (Card, UPI, Netbanking)
- View Booking History

### 🎛️ Admin Module
- Admin Login Panel
- Manage Movies (Add/Edit/Delete)
- Manage Theaters (Add/Edit/Delete)
- Manage Showtimes
